Kepuli-TV plays the user's own Xtream Codes account, M3U playlist or Stalker portal. It contains no media, provider addresses or bundled credentials, runs in its own extension tab, and has no content scripts, analytics or developer backend. Channel logos may load as <img> from raw.githubusercontent.com/tv-logo/tv-logos, a public collection whose file list ships in js/logoindex.js.

1.6.3: no new permission since 1.6.0. declarativeNetRequestWithHostAccess is used only for a Stalker (MAG box) portal (js/stalker.js, portalRule): a session rule sets the MAC address cookie, a MAG User-Agent and Referer on requests to that portal's host alone, on hosts the user granted. Recording (js/recorder.js, js/streamhub.js) writes a live stream to the extension's OPFS; Save is an <a download> of a Blob. Also: optional storage.sync (off by default; passwords only if ticked), runtime.setUninstallURL carrying only version, browser and language, and an "Allow all addresses" click that may call permissions.request for the declared optional http://*/* and https://*/*.

For review, the source archive includes a local mock server. With native FFmpeg installed, run sh dev/mock/media.sh and node dev/mock/server.mjs (see README.md). No paid account is needed.

The manifest requires Firefox 140 and declares authenticationInfo because the user's credentials are sent to their configured service. The developer receives no data. HTTP stays for user-supplied services; Settings says it sends credentials unencrypted and recommends HTTPS. We request a determination under the user-supplied-service cases in Mozilla's policy Q&A: https://discourse.mozilla.org/t/add-ons-policy-changes-2021-q-a/89654

All executable code ships inside the ZIP. vendor/hls.js is the unmodified dist/hls.min.js of hls.js 1.6.5; vendor/mpegts.js the unmodified dist/mpegts.js of mpegts.js 1.8.0, both compared byte for byte with npm:
https://www.npmjs.com/package/hls.js/v/1.6.5
https://www.npmjs.com/package/mpegts.js/v/1.8.0

vendor/ffaudio is our Emscripten 6.0.9 build of FFmpeg n7.1.1. The source ZIP contains the full FFmpeg source, our C wrapper and the exact build commands in its README.md. LGPL-2.1-or-later; no GPL or nonfree flags.

Every innerHTML and insertAdjacentHTML write is a fixed SVG constant with no user or provider input; dev/htmlcheck.mjs enforces it. Function-constructor warnings come from the unchanged upstream mpegts.js; the CSP forbids string evaluation. No remote code is loaded.
