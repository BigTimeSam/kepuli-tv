Kepuli-TV — Microsoft Edge Add-ons: the Partner Center fields
=============================================================
Edge runs the Chrome package as it is (dev/AGENTS.md), so what goes to this
store is that package under its own name and the Chrome listing's texts.
This file holds what Partner Center asks, in the order it asks it. Where a
text is the Chrome dashboard's, it is named and not repeated: it lives in
store/chrome-dashboard.txt.

The product was made on 2026-11-18 with 1.14.0, filled in whole and sent
for certification by the owner that evening: the overview says "In
review". Nothing is uploaded or sent for certification
without the owner's go in the conversation at hand (AGENTS.md, rule 2).

What Microsoft says of the form was read on 2026-11-18, at
learn.microsoft.com/microsoft-edge/extensions/publish/ (create-dev-account,
publish-extension) and …/extensions/update/api/using-addons-api. Read them
again before relying on a limit below.

How the form behaves (measured that day, driven in the owner's Chrome):
  • A description set by script is not taken as a change: Save draft
    stays grey until a key is pressed in the field (a space and a
    backspace are enough).
  • Screenshots uploaded together land in the order their uploads end.
    Upload them one at a time and wait for each to show.
  • "Duplicate … for all languages" under the logo, the tiles and the
    screenshots copies the pictures to every language; the video and
    the search terms stay the language's own.
  • With the last language complete the editor's Close gives way to
    Publish, which opens the notes for certification.

--- NOTES FOR CERTIFICATION -------------------------------------------------
Asked on the last page, with every submission: "Yes, I need to provide
credentials, accounts, or other info for testers", and at most 2,000
characters.
Microsoft's testers run the extension; they will not build a server. The
project's hosted demo (the invented provider of dev/mock/, on Fly.io, made
for the App Store's review) serves them too. Its address is "demoUrl" in
~/.config/kepuli-tv/ios/appstore.json and replaces <DEMO HOST> below when
the notes are pasted; it is never written here.

The extension plays the user's own IPTV subscription and contains no content. To test it, use this demo account (invented content only, made for review):

1. Click the extension's toolbar button: the player opens in a tab.
2. In the account form choose Xtream Codes. Protocol: HTTPS. Server: <DEMO HOST>. Port: 443. Username: demo. Password: demo. Press Connect and allow access to that one host when Edge asks.
3. Choose a country and a channel: it plays. Press g for the programme guide.
4. Movies and Series hold demo films; Series > Nordic Noir > Silent Fjord is an MKV file with subtitles.

Every title, channel and programme in the demo is fictional and belongs to the project. The source is at github.com/BigTimeSam/kepuli-tv.


--- AFTER THE FIRST PUBLICATION: THE PUBLISH API ----------------------------
A new product is made in Partner Center, and so are its texts and
pictures: the API has no endpoint for either. What it does is replace the
package of a product that exists and send it for certification, which is
what a release needs. No tool for it is written yet; when the product
exists:

  Partner Center → Microsoft Edge → Publish API → Enable the new
  experience (v1.1) → Create API credentials: a Client ID and an API key
  (it has an expiry date). With the product's ID (the GUID in the
  dashboard's address, between microsoftedge/ and /packages) they go to
  ~/.config/kepuli-tv/edge.json, mode 600, outside the project.

  Base  https://api.addons.microsoftedge.microsoft.com
  Headers  Authorization: ApiKey <key>, X-ClientID: <client id>
  POST /v1/products/<id>/submissions/draft/package   (application/zip)
  GET  /v1/products/<id>/submissions/draft/package/operations/<operation>
  POST /v1/products/<id>/submissions                 ({"notes": "…"})
  GET  /v1/products/<id>/submissions/operations/<operation>

Certification can take up to seven business days.
