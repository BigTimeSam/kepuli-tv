IPTV-плеер для Chrome

Kepuli-TV — расширение для Google Chrome 116 или новее, которое воспроизводит твою подписку на IPTV во вкладке: каналы в прямом эфире с телегидом, фильмы и сериалы. Оно бесплатное, с открытым исходным кодом, регистрации у нас нет, и своих каналов в нём нет.

Установить в Chrome Добавить в Firefox

На Android Kepuli-TV устанавливается в Firefox: как его настроить.

На iPhone Kepuli-TV устанавливается в браузер Orion: как его настроить.

Установка в Chrome

  1. Открой Kepuli-TV в интернет-магазине Chrome кнопкой выше и нажми Установить.
  2. Нажми на значок пазла на панели инструментов Chrome и закрепи Kepuli-TV, чтобы его значок оставался на виду.
  3. Нажми на значок. Плеер откроется в отдельной вкладке и спросит данные твоего провайдера.

Подключи свою подписку

Вставь адрес, который прислал провайдер. Форма сама определит, что это: плейлист M3U, аккаунт Xtream Codes или портал Stalker. Затем Chrome спросит, можно ли Kepuli-TV обращаться к этому серверу: выбери Разрешить, разрешение касается только этого сервера.

Что добавляет Chrome

  • Chromecast: файл, который Chrome воспроизводит сам, отправляется на устройство из меню плеера, а для остального меню объясняет, как это делает собственная трансляция вкладки Chrome.
  • Картинка в картинке из того же меню, для канала, который остаётся в углу экрана, пока ты работаешь.
  • Два канала рядом, если подписка допускает два потока одновременно или у тебя есть второй аккаунт.
  • Синхронизация между компьютерами через собственную синхронизацию Chrome, выключенная, пока ты её не включишь.

Полезно знать

  • Chrome на Android и на iPhone расширений не устанавливает. Для телефона см. Android и iPhone.
  • Файлы MKV играют во вкладке, с перемоткой, со звуком AC-3, E-AC-3 и DTS: см. MKV в браузере.
  • Всё остальное есть в руководстве пользователя (на английском).

Установи Kepuli-TV
