# IPTV-Player für Chrome

Kepuli-TV ist eine Erweiterung für Google Chrome 116 oder neuer, die dein
eigenes IPTV-Abo in einem Tab abspielt: Live-Kanäle mit Programmübersicht,
Filme und Serien. Sie ist kostenlos und quelloffen, es gibt kein Konto bei
uns, und eigene Kanäle bringt sie nicht mit.

## In Chrome installieren

1. Öffne Kepuli-TV mit der Schaltfläche oben im Chrome Web Store und wähle
   **Hinzufügen**.
2. Klicke in der Symbolleiste von Chrome auf das Puzzleteil und hefte
   Kepuli-TV an, damit das Symbol sichtbar bleibt.
3. Klicke auf das Symbol. Der Player öffnet sich in einem eigenen Tab und
   fragt nach den Daten deines Anbieters.

## Dein Abo verbinden

Füge die Adresse ein, die dein Anbieter dir geschickt hat. Das Formular
erkennt, um welche Art es sich handelt: eine
[M3U-Playlist](/m3u-playlist-player/), ein
[Xtream-Codes-Konto](/xtream-codes-player/) oder ein
[Stalker-Portal](/stalker-portal-player/). Chrome fragt dann, ob Kepuli-TV
diesen Server erreichen darf: Wähle **Zulassen**, das gilt nur für diesen
Server.

## Was Chrome dazugibt

- **Chromecast**: Eine Datei, die Chrome selbst abspielt, geht über das Menü
  des Players an das Gerät, und für alles andere erklärt das Menü, wie
  Chromes eigene Tab-Übertragung das erledigt.
- **Bild-in-Bild** aus demselben Menü, für einen Kanal, der in einer Ecke
  des Bildschirms bleibt, während du arbeitest.
- **Zwei Kanäle nebeneinander**, wenn dein Abo zwei Streams gleichzeitig
  erlaubt oder du ein zweites Konto hast.
- **Synchronisierung zwischen Computern** über Chromes eigene
  Synchronisierung, aus, bis du sie einschaltest.

## Gut zu wissen

- Chrome auf Android und auf dem iPhone installiert keine Erweiterungen. Für
  das Handy siehe [Android](/iptv-player-android/) und
  [iPhone](/iptv-player-iphone/).
- MKV-Dateien laufen im Tab, samt Spulen, mit AC-3-, E-AC-3- und DTS-Ton:
  siehe [MKV im Browser](/mkv-player-browser/).
