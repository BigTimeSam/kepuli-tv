# Lecteur IPTV pour Chrome

Kepuli-TV est une extension pour Google Chrome 116 ou plus récent qui lit
votre propre abonnement IPTV dans un onglet : les chaînes en direct avec un
guide des programmes, les films et les séries. Elle est gratuite et open
source, il n’y a pas de compte à créer chez nous, et elle est livrée sans
aucune chaîne.

## L’installer dans Chrome

1. Ouvrez Kepuli-TV dans le Chrome Web Store avec le bouton ci-dessus et
   choisissez **Ajouter à Chrome**.
2. Cliquez sur la pièce de puzzle dans la barre d’outils de Chrome et
   épinglez Kepuli-TV, pour que son icône reste visible.
3. Cliquez sur l’icône. Le lecteur s’ouvre dans son propre onglet et demande
   les informations de votre fournisseur.

## Connecter votre abonnement

Collez l’adresse envoyée par votre fournisseur. Le formulaire reconnaît de
quoi il s’agit : une [playlist M3U](/m3u-playlist-player/), un
[compte Xtream Codes](/xtream-codes-player/) ou un
[portail Stalker](/stalker-portal-player/). Chrome demande ensuite si
Kepuli-TV peut accéder à ce serveur : choisissez **Autoriser**, ce qui ne
vaut que pour ce serveur.

## Ce que Chrome apporte

- **Chromecast** : un fichier que Chrome lit de lui-même part vers
  l’appareil depuis le menu du lecteur ; pour le reste, le menu explique
  comment y parvenir avec la diffusion d’onglet de Chrome.
- **Image dans l’image**, depuis le même menu, pour une chaîne qui reste
  dans un coin de l’écran pendant que vous travaillez.
- **Deux chaînes côte à côte**, si votre abonnement autorise deux flux à la
  fois ou si vous avez un second compte.
- **La synchronisation entre ordinateurs** par celle de Chrome, désactivée
  tant que vous ne l’activez pas.

## À savoir

- Chrome sur Android et sur iPhone n’installe pas d’extensions. Sur un
  téléphone, voir [Android](/iptv-player-android/) et
  [iPhone](/iptv-player-iphone/).
- Les fichiers MKV se lisent dans l’onglet, déplacement dans le fichier
  compris, avec le son AC-3, E-AC-3 et DTS : voir
  [Le MKV dans le navigateur](/mkv-player-browser/).
- Tout le reste est dans le [guide d’utilisation](https://github.com/BigTimeSam/kepuli-tv/blob/main/docs/user-guide.md) (en anglais).
