# Lecteur IPTV pour Android, dans Firefox

Sur un téléphone ou une tablette Android, Kepuli-TV fonctionne dans Firefox,
qui y installe les modules complémentaires comme sur un ordinateur. Chrome
pour Android n’installe pas d’extensions : ce sera donc Firefox. Vous
retrouvez le même lecteur : les chaînes en direct avec un guide des
programmes, les films et les séries de votre propre playlist M3U, compte
Xtream Codes ou portail Stalker.

## L’installer sur Android

1. Installez [Firefox](https://play.google.com/store/apps/details?id=org.mozilla.firefox)
   (142 ou plus récent) depuis le Play Store.
2. Ouvrez cette page dans Firefox et choisissez **Ajouter à Firefox**
   ci-dessus, ou choisissez **Extensions** dans le menu de Firefox et
   cherchez-y Kepuli-TV.
3. Ouvrez le menu de Firefox, choisissez **Extensions** puis **Kepuli-TV**.
   Le lecteur s’ouvre dans un onglet.
4. Collez l’adresse envoyée par votre fournisseur et appuyez sur **Se
   connecter**. Firefox demande si Kepuli-TV peut accéder à ce serveur :
   choisissez **Autoriser**.

## Ce qui change sur un téléphone

- **Les listes et le guide s’adaptent à l’écran.** Les filtres se replient,
  et le [guide des programmes](/iptv-epg-guide/) laisse presque tout l’écran
  à sa grille : balayez pour vous déplacer dans le temps, touchez un
  programme pour voir ses détails.
- **Plein écran** est un bouton de l’en-tête, et fait aussi disparaître les
  barres du système.
- **Ouvrir dans VLC**, dans le menu du lecteur, passe le flux à
  l’application VLC, qui peut l’envoyer vers un Chromecast. Sans VLC, le
  Play Store s’ouvre sur sa page.
- **Les films MKV se lisent avec le son**, AC-3, E-AC-3 et DTS compris :
  voir [Le MKV dans le navigateur](/mkv-player-browser/).
- **Deux chaînes côte à côte**, c’est pour une tablette ; sur l’écran d’un
  téléphone, ce choix n’est pas proposé.
- **L’écran reste allumé** tant qu’une image est en lecture.

## À savoir
