# Lecteur IPTV pour Firefox

Kepuli-TV est un module complémentaire pour Mozilla Firefox 130 ou plus
récent qui lit votre propre abonnement IPTV dans un onglet : les chaînes en
direct avec un guide des programmes, les films et les séries. Le même module
fonctionne dans [Firefox pour Android](/iptv-player-android/) et, grâce à
Orion, sur [iPhone](/iptv-player-iphone/). Il est gratuit et open source, et
il est livré sans aucune chaîne.

## L’installer dans Firefox

1. Ouvrez Kepuli-TV sur Firefox Add-ons avec le bouton ci-dessus et
   choisissez **Ajouter à Firefox**.
2. Cliquez sur l’icône de Kepuli-TV dans la barre d’outils. Si elle n’y est
   pas, elle se trouve sous la pièce de puzzle, d’où on peut l’épingler à la
   barre d’outils.
3. Le lecteur s’ouvre dans son propre onglet et demande les informations de
   votre fournisseur.

## Connecter votre abonnement

Collez l’adresse envoyée par votre fournisseur. Le formulaire reconnaît de
quoi il s’agit : une [playlist M3U](/m3u-playlist-player/), un
[compte Xtream Codes](/xtream-codes-player/) ou un
[portail Stalker](/stalker-portal-player/). Firefox demande ensuite si
Kepuli-TV peut accéder à ce serveur : choisissez **Autoriser**, ce qui ne
vaut que pour ce serveur. Rien n’est envoyé nulle part avant cela.

## La lecture dans Firefox

- **Les fichiers MKV** sont déballés dans l’onglet et se lisent avec
  déplacement dans le fichier. Firefox n’a pas de décodeur pour le son AC-3,
  E-AC-3 ou DTS : le lecteur apporte donc le sien. Voir
  [Le MKV dans le navigateur](/mkv-player-browser/).
- **Les logos et les jaquettes** qu’un fournisseur sert en simple http
  s’affichent aussi dans Firefox.
- **La synchronisation entre ordinateurs** passe par celle de Firefox, et
  reste désactivée tant que vous ne l’activez pas.
- **Chromecast** n’est pas proposé : Firefox n’a aucun moyen d’en atteindre
  un. À la place, le menu du lecteur passe le flux à VLC ou à un autre
  lecteur.

## À savoir

- Le [guide des programmes](/iptv-epg-guide/), le replay, l’enregistrement
  et les trente langues sont les mêmes que dans Chrome.
- Tout le reste est dans le [guide d’utilisation](https://github.com/BigTimeSam/kepuli-tv/blob/main/docs/user-guide.md) (en anglais).
