# Pemutar IPTV untuk Chrome

Kepuli-TV adalah ekstensi untuk Google Chrome 116 atau lebih baru yang
memutar langganan IPTV milikmu di sebuah tab: saluran langsung dengan
panduan acara, film, dan serial. Gratis dan sumber terbuka, tidak ada akun
pada kami, dan tidak ada saluran bawaan.

## Memasang di Chrome

1. Buka Kepuli-TV di Chrome Web Store lewat tombol di atas dan pilih
   **Tambahkan ke Chrome**.
2. Klik ikon kepingan puzzle di bilah alat Chrome dan sematkan Kepuli-TV,
   supaya ikonnya selalu terlihat.
3. Klik ikonnya. Pemutar terbuka di tab tersendiri dan meminta data dari
   penyediamu.

## Menghubungkan langganan

Tempel alamat yang dikirim penyedia. Formulir mengenali sendiri jenisnya:
[daftar putar M3U](/m3u-playlist-player/),
[akun Xtream Codes](/xtream-codes-player/), atau
[portal Stalker](/stalker-portal-player/). Chrome lalu bertanya apakah
Kepuli-TV boleh menjangkau server itu: pilih **Izinkan**, yang berlaku
untuk server itu saja.

## Yang ditambahkan Chrome

- **Chromecast**: file yang bisa diputar Chrome sendiri dikirim ke perangkat
  dari menu pemutar, dan untuk sisanya menu menjelaskan caranya lewat fitur
  transmisi tab milik Chrome.
- **Picture-in-picture** dari menu yang sama, untuk saluran yang tetap
  tampil di sudut layar selagi kamu bekerja.
- **Dua saluran berdampingan**, jika langgananmu mengizinkan dua siaran
  sekaligus atau kamu punya akun kedua.
- **Sinkronisasi antarkomputer** lewat sinkronisasi milik Chrome, mati
  sampai kamu menyalakannya.

## Perlu diketahui

- Chrome di Android dan di iPhone tidak memasang ekstensi. Untuk ponsel,
  lihat [Android](/iptv-player-android/) dan
  [iPhone](/iptv-player-iphone/).
- File MKV diputar di tab, termasuk lompat ke bagian mana pun, dengan suara
  AC-3, E-AC-3, dan DTS: lihat [MKV di browser](/mkv-player-browser/).
- Selebihnya ada di [panduan pengguna](https://github.com/BigTimeSam/kepuli-tv/blob/main/docs/user-guide.md) (dalam bahasa Inggris).
