# Pemutar IPTV untuk Firefox

Kepuli-TV adalah pengaya untuk Mozilla Firefox 130 atau lebih baru yang
memutar langganan IPTV milikmu di sebuah tab: saluran langsung dengan
panduan acara, film, dan serial. Pengaya yang sama berjalan di
[Firefox untuk Android](/iptv-player-android/) dan, lewat Orion, di
[iPhone](/iptv-player-iphone/). Gratis dan sumber terbuka, dan tidak ada
saluran bawaan.

## Memasang di Firefox

1. Buka Kepuli-TV di Firefox Add-ons lewat tombol di atas dan pilih
   **Tambahkan ke Firefox**.
2. Klik ikon Kepuli-TV di bilah alat. Jika tidak ada di sana, ikonnya ada
   di bawah kepingan puzzle, dan dari situ bisa disematkan ke bilah alat.
3. Pemutar terbuka di tab tersendiri dan meminta data dari penyediamu.

## Menghubungkan langganan

Tempel alamat yang dikirim penyedia. Formulir mengenali sendiri jenisnya:
[daftar putar M3U](/m3u-playlist-player/),
[akun Xtream Codes](/xtream-codes-player/), atau
[portal Stalker](/stalker-portal-player/). Firefox lalu bertanya apakah
Kepuli-TV boleh menjangkau server itu: pilih **Izinkan**, yang berlaku
untuk server itu saja. Sebelum itu tidak ada yang dikirim ke mana pun.

## Cara pemutarannya di Firefox

- **File MKV** dibongkar di tab dan bisa dilompati ke bagian mana pun.
  Firefox tidak punya dekoder untuk suara AC-3, E-AC-3, atau DTS, jadi
  pemutar membawa dekodernya sendiri: lihat
  [MKV di browser](/mkv-player-browser/).
- **Logo dan sampul** yang dikirim penyedia lewat http biasa juga tampil di
  Firefox.
- **Sinkronisasi antarkomputer** berjalan lewat sinkronisasi milik Firefox,
  dan mati sampai kamu menyalakannya.
- **Chromecast** tidak ditawarkan: Firefox tidak punya cara menjangkaunya.
  Sebagai gantinya, menu pemutar menyerahkan siaran ke VLC atau pemutar lain.
