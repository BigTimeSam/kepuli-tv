3.FFmpeg audio decoders

Sound in AC-3, E-AC-3 and DTS is decoded, and encoded to AAC, by a WebAssembly build of parts of FFmpeg (tag n7.1.5, © 2000–2024 the FFmpeg developers): the decoders ac3, eac3 and dca, the parsers ac3 and dca, and the encoder aac. FFmpeg is licensed under the GNU Lesser General Public License, version 2.1 or later. The build contains no GPL or non-free part, and FFmpeg's source is compiled as it is, with no changes.

The source and how to rebuild it. The complete build commands are in dev/wasm/build.sh of Kepuli-TV's repository, which fetches FFmpeg's source at the tag named above from github.com/FFmpeg/FFmpeg; the only code written against the library is dev/wasm/ffaudio.c. Running the script gives the same ffaudio.wasm, and another FFmpeg version gives the same interface from that version. The library is a file of its own (vendor/ffaudio/ffaudio.wasm), loaded when it is needed, and all of Kepuli-TV is open source, so the extension and the app can be built with a modified version of it.
